# Client 16.3 release

Client **16.3.0** is published on npm under `latest` and `next`. The exact tested
archive was installed from the registry, its integrity and README were compared,
and all 43 tools plus an exact calculation were verified against production core
**16.3.0**. The public npm README is 443 words and reflects the actual release.

The engine now has an internal qualification for bounded semantic review across
all 21 rubrics. Its composite evaluation blocks 202/210 defects, has four false
blocks and two false validations, and abstains on 24/420 cases. This is scoped
engineering qualification, not external accreditation or a universal correctness
guarantee. Read the [method, reuse, limits and full results](https://smart-thinking-site-923774092927.northamerica-northeast1.run.app/en/benchmarks/).

Website **2.2.0** and the assistant-specific installation guides are live. The
MCP profile and client behavior remain compatible with the earlier 16.x release.
