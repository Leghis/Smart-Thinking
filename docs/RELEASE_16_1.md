# 16.1.0

The client now uses one complete, paginated tool-discovery path for the bridge, JavaScript API and doctor. It verifies the full catalogue before applying profiles and preserves typed server errors. The doctor supports explicit loopback testing and reports connectivity separately from semantic-provider configuration.

The code profile includes `code_index`. A shared release manifest and generated 43-tool contract keep the client, engine and bilingual website aligned. The npm README now provides a short English introduction and links to separate assistant guides, examples, data information and evaluations.

Existing tools and the MCP 16.0 profile remain supported. The hosted engine adds durable native-sandbox execution and stronger evidence provenance. Its new semantic-review calibration did not meet production criteria; the site reports the measured limitations explicitly.

Publication and deployed revision evidence are recorded in the delivery report; this change description alone does not prove a deployment.
