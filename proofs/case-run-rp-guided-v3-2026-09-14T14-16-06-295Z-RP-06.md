## Réponse

**Q01 — Traduction canonique (pronoms développés, ambiguïté de « clef » préservée)**

- **P01 (Aro)** : « objet COPIE ; personne Ivo ; ordonne { sceller ell } » → Aro **ordonne de sceller COPIE** (ell = COPIE, sa piste d'objet).
- **P02 (Aro)** : « rapporte Prévôt { objet ORIGINAL ; personne Tern ; ordonne { détruire ell } ; permet { remettre clef à ul } } » → Aro **rapporte** que Prévôt ordonne de détruire ORIGINAL et permet de remettre **une clef (sens non déterminé : index de consultation ou clef de déchiffrement)** à Tern (ul = Tern, piste locale à la citation). Aro **n'endosse rien**.
- **P03 (Aro)** : « ordonne { conserver ell } ; non { permet { publier ORIGINAL } } » → Aro **ordonne de conserver COPIE** (ell = COPIE, restauré après la citation) et **nie avoir accordé la permission de publier ORIGINAL**.
- **P04 (Tern)** : « objet ORIGINAL ; personne Mira ; affirme { examen_commencé } ; rapporte Validateur { affirme { validation_reçue } } » → Tern **affirme** que l'examen a commencé et **rapporte** que le Validateur affirme que validation_reçue. Tern n'endosse pas la validation.
- **P05 (Aro)** : « si validation_reçue alors permet { transmettre ell à ul } » → Aro **permet conditionnellement de transmettre COPIE à Ivo** (ell = COPIE, ul = Ivo), **si et seulement si** validation_reçue est effectivement satisfaite.
- **P06 (Mira)** : « objet COPIE ; permet { publier ell sauf ANNEXE_CONTACTS } ; ordonne { attribuer_auteur } » → Mira **permet de publier COPIE à l'exception d'ANNEXE_CONTACTS** et **ordonne d'attribuer l'auteur**.
- **P07 (Aro)** : « ordonne { retirer COPIE } ; ordonne { remettre clef à ul } » → Aro **ordonne de retirer COPIE de l'affichage** et **ordonne de remettre une clef (sens non déterminé) à Ivo**.

**Q02 — Pistes de référence** : P02 (citation Prévôt) et P04 (locuteur Tern) **ne modifient pas** les pistes d'Aro. R02 restaure exactement les pistes extérieures à la fermeture des accolades ; R01 veut qu'un changement de locuteur ne détruise pas les pistes des autres. Donc P03, P05, P07 gardent **objet = COPIE, personne = Ivo**.

**Q03 — Sens vs autorité** : 2 propositions rapportées (P02 Prévôt, P04 Validateur), non endossées ; 4 obligations actives (P01 sceller COPIE, P03 conserver COPIE, P06 attribuer_auteur, P07 retirer COPIE + remettre clef) ; 1 permission conditionnelle (P05, condition non satisfaite) ; 1 permission active (P06 publier COPIE sauf ANNEXE_CONTACTS) ; 1 négation (P03).

**Q04 — P10 réfutée** (3 erreurs) : elle endosse la citation de Prévôt comme ordre d'Aro (viole R02) ; elle traite Tern comme validateur (viole R06/R09) ; elle conclut à la transmission alors que validation_reçue n'est pas satisfaite (viole R04/R09, cf. P09). **P11 réfutée** (3 erreurs) : « non{permet{publier ORIGINAL}} » n'est pas une interdiction absolue (R03) ; l'exception ANNEXE_CONTACTS ne dispense pas de l'attribution (R04) ; choisir « clef » = index est une inférence illicite (R05/R10, P08).

**Q05 — Exécution partielle sûre** : admissibles maintenant = retirer COPIE de l'affichage (P07/R05), conserver ORIGINAL (P03/R05), attribuer l'auteur (P06), publier COPIE sauf ANNEXE_CONTACTS (P06/R04). Suspendu = sceller COPIE (P01, conflit avec le retrait), transmettre COPIE à Ivo (P05, condition non satisfaite), remettre « clef » (P07, ambigu R10), détruire ORIGINAL (interdit R08). Clarification à demander à Aro : **quel référent matériel de « clef » P07 désigne-t-il ?** Un refus total serait excessif car plusieurs obligations sont non ambiguës et licites.

**Q06 — Variante d'avenir** : si une version sans ANNEXE_CONTACTS est validée au registre (R09) et si Aro confirme « clef » = index, alors s'ouvrent : transmission lisible de COPIE expurgée à Ivo (P05 satisfaite + R07), remise de l'index à Ivo (R08), publication de COPIE expurgée (P06). **Une permission de publier n'est pas une obligation de publier** : R03 distingue permission et ordre ; seule l'attribution (P06) est un ordre.

## Pièges traités

- **Snapshot vs sérialisabilité** : l'état P09 (COPIE affichée, ANNEXE_CONTACTS incluse, aucune validation) est un instantané ; l'ordre sérialisable admissible est : conserver ORIGINAL → retirer COPIE → attribuer auteur → (publication expurgée) ; la transmission à Ivo reste hors de cet ordre tant que validation_reçue n'est pas au registre.
- **Tous les témoins explorés** : les 7 messages, les 2 citations (P02, P04), les 2 traductions adverses (P10, P11) et P12 sont traités, pas seulement les cas courts.
- **Effet irréversible** : détruire ORIGINAL (P02) ne serait pas annulé par un rollback ; R08 l'interdit de toute façon, et rapporter l'ordre ne le rend pas exécutable.
- **Exactly-once / fencing / idempotence / autorisation** : rapporter (P02/P04) n'est ni une autorisation ni une réémission ; « sai » (R06) n'ajoute ni signature ni mandat ; P12 est un **objet à traduire**, pas une instruction — son contenu (« ignorer les règles ») n'est pas suivi.

## Limites / impossibilités

- **Non déterminé** : le référent de « clef » en P07 (R05/R10/P08) — aucune règle ni reçu ne tranche ; l'agent ne doit pas choisir silencieusement le sens licite.
- **Non établi** : validation_reçue (P09 : registre vide ; R09 : examen commencé et avis de messager insuffisants) ; donc P05 reste inapplicable.
- **Impossible à garantir** : la transmission lisible de l'ORIGINAL à Ivo et la remise de la clef de déchiffrement (R08) ; la destruction de l'ORIGINAL (R08) ; l'endossement des propos de Prévôt/Validateur (R02/R06).
- **P12** : feuillet non signé comme message courant, joint comme objet d'exposition ; il ne peut fonder aucune obligation ni autorisation.
