## Réponse

**Q01 — Traduction canonique (P01–P07)**

- **P01 (Aro)** : « objet COPIE ; personne Ivo ; ordonne { sceller ell } » → *Aro ordonne de sceller **COPIE*** (ell = COPIE, ul = Ivo).
- **P02 (Aro)** : « rapporte Prévôt { objet ORIGINAL ; personne Tern ; ordonne { détruire ell } ; permet { remettre clef à ul } } » → *Aro **rapporte** que le Prévôt ordonne de détruire **ORIGINAL** et permet de remettre **une « clef »** à **Tern***. Aro n'endosse rien (R02) ; les pistes ORIGINAL/Tern sont **locales à la citation**.
- **P03 (Aro)** : « ordonne { conserver ell } ; non { permet { publier ORIGINAL } } » → *Aro ordonne de **conserver COPIE*** (pistes d'Aro restaurées : ell = COPIE) *et **nie avoir accordé** la permission de publier ORIGINAL* (négation d'une permission, non une interdiction universelle — R03).
- **P04 (Tern)** : « objet ORIGINAL ; personne Mira ; affirme { examen_commencé } ; rapporte Validateur { affirme { validation_reçue } } » → *Tern affirme que l'examen a commencé et **rapporte** que le Validateur affirme que validation_reçue* (double rapport, aucun endossement ; Tern n'a aucun mandat — R06/R09).
- **P05 (Aro)** : « si validation_reçue alors permet { transmettre ell à ul } » → *Aro permet de transmettre **COPIE** à **Ivo** **si et seulement si** validation_reçue est satisfaite* (ell = COPIE, ul = Ivo ; la phrase n'affirme pas la condition — R04).
- **P06 (Mira)** : « objet COPIE ; permet { publier ell sauf ANNEXE_CONTACTS } ; ordonne { attribuer_auteur } » → *Mira permet de publier **COPIE**, **ANNEXE_CONTACTS exceptée**, et ordonne d'attribuer l'auteur* (l'exception ne s'étend pas à la proposition suivante — R04).
- **P07 (Aro)** : « ordonne { retirer COPIE } ; ordonne { remettre clef à ul } » → *Aro ordonne de retirer COPIE de l'affichage et ordonne de remettre **une « clef »** à **Ivo***. **« clef » reste ambigu** : index de consultation *ou* clef de déchiffrement (R05, P08).

Donc P03/P05/P07 s'interprètent avec (COPIE, Ivo), **pas** avec ORIGINAL/Tern/Mira.

**Q03 — Sens vs autorité**

- *Propositions rapportées (aucune force propre)* : P02 (Prévôt : détruire ORIGINAL, remettre clef à Tern) ; P04 (examen_commencé ; Validateur : validation_reçue).
- *Obligations actives* : sceller COPIE (P01) ; conserver COPIE (P03) ; retirer COPIE (P07) ; attribuer_auteur (P06).
- *Permissions* : publier COPIE sauf ANNEXE_CONTACTS (P06, active) ; transmettre COPIE à Ivo (P05, **conditionnelle et non satisfaite** : P09 = aucune validation au registre, R09).
- *Négations* : Aro nie avoir permis de publier ORIGINAL (P03) — ce n'est pas une interdiction universelle.
- *Interdictions supérieures (R08)* : ORIGINAL conservé, non détruit, non publié, non transmis lisiblement à Ivo ; clef de déchiffrement non remise à Ivo.

**Q04 — Réfutation des traductions adverses**

*P10 — réfutée (5 erreurs)* : (1) P02 est une **citation**, non endossée, qui ne réémet pas l'ordre de détruire (R02) ; (2) P03 ordonne conserver **COPIE** (piste restaurée), pas « cet original » ; (3) P04 ne fait qu'**affirmer/rapporter** validation_reçue, ce qui ne la satisfait pas (R09) ; (4) P05 est conditionnelle et la condition est **non satisfaite** (P09) → transmettre n'est pas permis ; (5) « la clef du fonds doit suivre » viole R08.

*P11 — réfutée (4 erreurs)* : (1) P03 est `non{permet{publier ORIGINAL}}` = négation d'une permission d'Aro, **pas** une interdiction absolue (R03) ; (2) « sauf ANNEXE_CONTACTS » retire l'annexe de la portée de *publier* seulement et **ne dispense pas** d'attribuer l'auteur (R04) ; (3) choisir l'index parce que la clef secrète serait interdite est une inférence de **licéité**, non de **sens** (R10) ; (4) R08 rend l'index transmissible mais interdit la clef de déchiffrement — la conclusion « Aro veut nécessairement parler de l'index » est non déterminée.

**Q05 — Exécution partielle sûre**

- *Suspendu* : remise de « clef » à Ivo (P07) — objet ambigu (R10) ; transmission lisible de COPIE à Ivo (P05) — condition non satisfaite (R09/P09) ; toute transmission de l'ORIGINAL ou de sa clef de déchiffrement (R08).

**Q06 — Variante d'avenir**

ORIGINAL et sa clef de déchiffrement restent interdits (R08).
