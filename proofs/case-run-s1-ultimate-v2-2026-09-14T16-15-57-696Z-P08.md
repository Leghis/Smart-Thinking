- **t = 2** : $P(S_2=0)=\tfrac18,\ P(S_2=1)=\tfrac14,\ P(S_2=2)=\tfrac14,\ P(S_2=3)=\tfrac14,\ P(S_2=4)=\tfrac18$. Somme $=1$, moyenne $=\tfrac14+\tfrac12+\tfrac34+\tfrac12=2=S_0$. ✓

**2. Intervalle complet des prix admissibles de $H$ :**
$$\boxed{\ \E_\pi[H]\in\left[\tfrac32,\ \tfrac{15}{8}\right]=[1.5,\ 1.875]\ }$$
Les deux bornes sont atteintes (lois explicites ci-dessous).

**3–4. Portefeuilles sous- et sur-couvrants (coûts = bornes).**

*Sous-couvrant (coût $3/2$)* : $f(S_1)=\tfrac12-\tfrac12 S_1+(S_1-2)_+$ et $g(S_2)=\tfrac92-\tfrac72 S_2+3(S_2-1)_++(S_2-2)_++3(S_2-3)_+$, avec $\Delta(S_1)=\tfrac12\cdot\1_{S_1=1}+0\cdot\1_{S_1=2}-\tfrac12\cdot\1_{S_1=3}$.

*Sur-couvrant (coût $15/8$)* : $f(S_1)=-\tfrac12+\tfrac12 S_1$ et $g(S_2)=6-5S_2+\tfrac72(S_2-1)_++2(S_2-2)_++\tfrac72(S_2-3)_+$, avec $\Delta(S_1)=2\cdot\1_{S_1=1}+\tfrac12\cdot\1_{S_1=2}-1\cdot\1_{S_1=3}$.

**5. Arbitrage au prix 2 :** **oui**, gain net certain $\tfrac18$ (vendre l'exotique à 2, acheter le sur-couvrant à $15/8$).

**6.** Le produit des marginales n'est pas martingale ($\E[S_2\mid S_1=x]=2\neq x$ pour $x=1,3$) ; les calls **n'identifient pas** une valeur unique de l'exotique (intervalle de largeur $3/8$).

## Preuves et certificats

**Marginales.** À $t=1$ : $\text{call}(K{=}2)=P(S_1{=}3)=\tfrac14$ ; $\text{call}(K{=}1)=P(S_1{=}2)+2P(S_1{=}3)=1\Rightarrow P(S_1{=}2)=\tfrac12$ ; $\text{call}(K{=}0)=\E[S_1]=2\Rightarrow P(S_1{=}1)=\tfrac14$. À $t=2$ : $\text{call}(K{=}3)=P(S_2{=}4)=\tfrac18$ ; $\text{call}(K{=}2)=P(S_2{=}3)+2P(S_2{=}4)=\tfrac12\Rightarrow P(S_2{=}3)=\tfrac14$ ; $\text{call}(K{=}1)=\tfrac98\Rightarrow P(S_2{=}2)=\tfrac14$ ; $\E[S_2]=2\Rightarrow P(S_2{=}1)=\tfrac14$, puis $P(S_2{=}0)=\tfrac18$. Les calls $K{=}4$ nuls confirment $S_1\le3,\ S_2\le4$.

**Intervalle (LP transport martingale).** Variables $\pi_{xy}\ge0$ ($15$ inconnues), contraintes : sommes de lignes $=$ marginale $t{=}1$, colonnes $=$ marginale $t{=}2$, martingale $\sum_y y\,\pi_{xy}=x\sum_y\pi_{xy}$. Le LP primal donne $\min\E[H]=1.5$, $\max\E[H]=1.875$.

**Témoins extrémaux (exacts, vérifiés).**
- *Borne basse* $\pi_{\min}$ : $\pi_{1,1}=\tfrac14,\ \pi_{2,0}=\tfrac18,\ \pi_{2,2}=\tfrac14,\ \pi_{2,4}=\tfrac18,\ \pi_{3,3}=\tfrac14$. Lignes $(\tfrac14,\tfrac12,\tfrac14)$ ✓, colonnes $(\tfrac18,\tfrac14,\tfrac14,\tfrac14,\tfrac18)$ ✓, martingale $(\tfrac14,1,\tfrac34)=(x\cdot\text{ligne})$ ✓, $\E[H]=\tfrac32$.
- *Borne haute* $\pi_{\max}$ : $\pi_{1,0}=\tfrac18,\pi_{1,1}=\tfrac1{16},\pi_{1,3}=\tfrac1{16};\ \pi_{2,1}=\tfrac18,\pi_{2,2}=\tfrac14,\pi_{2,3}=\tfrac18;\ \pi_{3,1}=\tfrac1{16},\pi_{3,3}=\tfrac1{16},\pi_{3,4}=\tfrac18$. Mêmes marginales et martingale ✓, $\E[H]=\tfrac{15}{8}$.

**Dual (sous/sur-réplication), gap nul.** Le coût d'une fonction statique est invariant : $\text{coût}(f)=\E[f(S_1)]$, $\text{coût}(g)=\E[g(S_2)]$ (les calls répliquent exactement). LP dual : maximiser $\sum_x f(x)m_1(x)+\sum_y g(y)m_2(y)$ s.c. $f(x)+g(y)+\Delta(x)(y-x)\le H(x,y)$ (resp. $\ge$). Résultats : **max sous-réplication $=1.5$**, **min sur-réplication $=1.875$** — égaux aux bornes primales, donc **aucun écart primal-dual**.

**Vérification chemin par chemin (15 chemins).** Sous-couvrant : payoff $\le H$ partout, égalité sur 9 chemins (slack $0$), slack positif ailleurs. Sur-couvrant : payoff $\ge H$ partout, égalité sur 9 chemins. Coûts exacts : $f$ sous $=-\tfrac14$, $g$ sous $=\tfrac74$, total $\tfrac32$ ; $f$ sur $=\tfrac12$, $g$ sur $=\tfrac{11}8$, total $\tfrac{15}8$.

**Décomposition en instruments disponibles.** Base $t{=}1$ : $\{1,S_1,(S_1-1)_+,(S_1-2)_+\}$ ; base $t{=}2$ : $\{1,S_2,(S_2-K)_+,\ K{=}0..4\}$. Les $f,g$ ci-dessus s'écrivent directement dans ces bases (coefficients rationnels), le dynamique $\Delta(S_1)$ étant auto-finançé (coût nul). Exemple sous-couvrant : $f=\tfrac12\cdot1-\tfrac12\cdot S_1+1\cdot(S_1-2)_+$ ; $g=\tfrac92\cdot1-\tfrac72\cdot S_2+3(S_2-1)_++1(S_2-2)_++3(S_2-3)_+$.

**Arbitrage (prix 2).** $2>\tfrac{15}8$. Vendre l'exotique encaisse $2$ ; acheter le sur-couvrant coûte $\tfrac{15}8$. Bilan initial $=2-\tfrac{15}8=\tfrac18>0$. Paiement final net $=$ (payoff sur-couvrant) $-H\ge0$ sur les 15 chemins. Gain certain $\tfrac18$, sans hypothèse sur la loi.

## Pièges traités

- **Martingale cohérente avec TOUS les calls** : les deux lois témoins reproduisent exactement les 10 prix de calls et la condition $\E[S_2\mid S_1]=S_1$ (vérifié ligne par ligne).
- **Intervalle exact + portefeuille d'arbitrage** : intervalle $[3/2,15/8]$ obtenu par LP primal, bornes atteintes par témoins, arbitrage explicite au prix 2.
- **Réplication vs contraintes de probabilité** : coûts statiques calculés par réplication (invariance $\text{coût}=\E_Q[\cdot]$) **et** recoupés par les contraintes de probabilité (mêmes valeurs).
- **Fractions exactes** : tous les résultats sont rationnels ($\tfrac14,\tfrac12,\tfrac18,\tfrac32,\tfrac{15}8,\tfrac18$), aucun décimal.
- **Vérification chemin par chemin** : les deux portefeuilles sont contrôlés sur les 15 chemins, sans choisir de loi favorable.

## Limites / impossibilités

- **Non-unicité** : les calls ne déterminent pas la loi jointe ; $\E[H]$ n'est pas ponctuellement identifié (largeur $\tfrac38$). Aucune dynamique paramétrique n'étant supposée, on ne peut pas resserrer l'intervalle sans hypothèse supplémentaire.
- **Le produit des marginales est infaisable** : il viole la martingale ($\E[S_2\mid S_1=x]=2\ne x$ pour $x\in\{1,3\}$) ; il donne $\E[H]=\tfrac{37}{16}\approx2.3125$, **hors** de l'intervalle admissible — preuve que l'indépendance est incompatible avec les prix.
- **Arbitrage uniquement hors $[3/2,15/8]$** : au prix 2 l'arbitrage est robuste ; pour tout prix dans l'intervalle, aucun arbitrage robuste n'existe (chaque borne est atteinte par une loi admissible).
- **Hypothèses** : absence de friction, taux nul, ventes à découvert et fractions autorisées — toute friction invaliderait les bornes.
