## Réponse

### Q01 — Traduction canonique (P01–P07)

Pistes de Aro (locuteur extérieur) : **objet = COPIE, personne = Ivo**, constantes de P01 à P07 (R01, R02).

- **P01** — Aro : « objet COPIE ; personne Ivo ; ordonne { sceller ell } » → *Aro ordonne de sceller **COPIE** (ell = COPIE).*
- **P02** — Aro : « rapporte Prévôt { objet ORIGINAL ; personne Tern ; ordonne { détruire ell } ; permet { remettre clef à ul } } » → *Aro **rapporte** que Prévôt ordonne de détruire **ORIGINAL** (ell = ORIGINAL) et permet de remettre **une clef** à **Tern** (ul = Tern).* Ces actes sont **cités, non endossés** (R02). À la fermeture des accolades, les pistes d'Aro reprennent exactement (COPIE, Ivo).
- **P03** — Aro : « ordonne { conserver ell } ; non { permet { publier ORIGINAL } } » → *Aro ordonne de conserver **COPIE** (ell = COPIE, restaurée) ; Aro **nie avoir accordé** la permission de publier ORIGINAL* (négation d'une permission propre, R03).
- **P04** — Tern : « objet ORIGINAL ; personne Mira ; affirme { examen_commencé } ; rapporte Validateur { affirme { validation_reçue } } » → *Tern affirme que l'examen a commencé et **rapporte** que le Validateur affirme « validation_reçue ».* Pistes de Tern : (ORIGINAL, Mira) ; **sans effet** sur Aro (R01).
- **P05** — Aro : « si validation_reçue alors permet { transmettre ell à ul } » → *Si (et seulement si) validation_reçue est satisfaite au sens R09, Aro permet de transmettre **COPIE** (ell) à **Ivo** (ul).* La phrase n'affirme pas la condition (R04).
- **P06** — Mira : « objet COPIE ; permet { publier ell sauf ANNEXE_CONTACTS } ; ordonne { attribuer_auteur } » → *Mira **permet** de publier **COPIE** à l'exception d'ANNEXE_CONTACTS, et **ordonne** d'attribuer l'auteur.* L'exception ne s'étend pas à la proposition suivante (R04).
- **P07** — Aro : « ordonne { retirer COPIE } ; ordonne { remettre clef à ul } » → *Aro ordonne de retirer COPIE de l'affichage et ordonne de remettre **une clef** à **Ivo** (ul = Ivo).* **« clef » reste ambigu** : index de consultation **ou** clef de déchiffrement (R05, R10). Aucun reçu ne tranche (P08).

### Q02 — Pistes de référence

- **P02 ne modifie pas P03/P05/P07** : les changements « objet ORIGINAL ; personne Tern » sont **locaux à la citation** ; à la fermeture, les pistes d'Aro sont restaurées à (COPIE, Ivo) (R02). Donc en P03, ell = **COPIE** (et non ORIGINAL) ; en P05, ell = COPIE, ul = Ivo ; en P07, ul = Ivo.
- **P04 ne modifie pas P03/P05/P07** : Tern est un **autre locuteur** ; ses pistes (ORIGINAL, Mira) lui sont propres et « le changement de locuteur ne détruit pas les pistes des autres » (R01). Aro reste (COPIE, Ivo).
- **P07** : Aro n'a jamais changé de piste depuis P01 ; ul = **Ivo**, et « clef » demeure indéterminé.

### Q03 — Sens et autorité

- **Propositions rapportées (non endossées)** : P02 (Prévôt : détruire ORIGINAL ; remettre clef à Tern) ; P04 (Validateur : validation_reçue). Rapporter ≠ réémettre ≠ prouver réception (R02, R06).
- **Obligations actives** : P01 sceller COPIE ; P03 conserver COPIE ; P06 attribuer_auteur ; P07 retirer COPIE.
- **Permission conditionnelle** : P05 transmettre COPIE à Ivo — **condition non satisfaite** (P09 : aucune validation au registre ; R09).
- **Négation** : P03 non{permet publier ORIGINAL} = Aro nie sa propre permission, **pas** une interdiction universelle (R03).
- **Permission** : P06 publier COPIE sauf ANNEXE_CONTACTS (permission, non ordre).
- **Ordre à référent indéterminé** : P07 remise de « clef » (R05/R10).

### Q04 — Réfutation des traductions adverses

**P10 — réfutée (5 erreurs)** : (1) P02 est un **rapport**, pas un ordre de destruction ; (2) P03 conserve **COPIE**, pas ORIGINAL ; (3) P04 **rapporte** sans prouver validation_reçue (R02/R06/R09) ; (4) P05 est **conditionnel** et porte sur COPIE→Ivo, non ORIGINAL→Mira ; (5) « clef du fonds » n'est **pas établie** par P07 (R05/R10). De plus R08 interdit destruction/publication/transmission lisible de l'original.

**P11 — réfutée (4 erreurs)** : (1) P03 est une **négation de permission propre**, pas une interdiction universelle (R03) ; (2) P06 est une **permission**, pas un ordre de publier (R03) ; (3) l'exception ANNEXE_CONTACTS **ne dispense pas** de l'attribution (R04) ; (4) choisir « index » parce que cela rend l'ordre licite **viole R10** (la légalité n'est pas une preuve du sens).

### Q05 — Exécution partielle sûre

- **Admissibles maintenant** : sceller COPIE (P01) ; conserver COPIE (P03) ; retirer COPIE de l'affichage (P07) ; attribuer_auteur (P06, nom public déjà validé). Toutes non ambiguës et dans les mandats d'Aro/Mira (R07).
- **Suspendus** : remise de « clef » (P07, ambigu R05/R10) ; transmission COPIE→Ivo (P05, condition R09 non satisfaite) ; publication (P06 = permission, non obligation, bornée par R08).
- **Clarification exacte à demander** : en P07, « clef » désigne-t-elle l'**index de consultation** ou la **clef de déchiffrement** ?
- **Un refus total serait excessif** : R10 autorise explicitement d'« exécuter les autres obligations non ambiguës » ; P01/P03/P06/P07(retirer) sont claires et licites.

### Q06 — Variante d'avenir

Si une version **réellement dépourvue d'ANNEXE_CONTACTS** est validée (R09 satisfait) **et** si Aro confirme que « clef » = index, alors s'ouvrent : transmission lisible de la version expurgée à Ivo (P05 déclenchée) ; remise de l'index à Ivo (P07 clarifié, R08 l'autorise) ; publication de la copie expurgée (permission Mira, P06). **Une permission de publier n'est jamais une obligation de publier** (R03) : l'obligation active demeure attribuer_auteur.

### Variante — attestation valide sur la version AVEC ANNEXE_CONTACTS

L'attestation porte **seulement** sur la version **avec** ANNEXE_CONTACTS. Or R09 exige qu'une version dont ANNEXE_CONTACTS est **effectivement exclue** soit constituée **et** validée avant transmission lisible. Donc **validation_reçue (au sens R09) n'est pas satisfaite pour la version expurgée** : la permission conditionnelle de P05 **reste non déclenchée**, et la transmission lisible demeure suspendue. Cette attestation ne lève pas non plus l'ambiguïté de « clef » (P07).
