- $b>a_p$ : $v_p(F)=b+a_p$, racine ssi $b+a_p\ge n_p$ ;
- $b=a_p$ : $v_p(F)=2a_p+v_p(w-d)$ avec $d=D/p^{a_p}$ unité, racine ssi $v_p(w-d)\ge n_p-2a_p$.

Paramétrisation sans doublon de $S$ : par le TCR, $x\mapsto(x\bmod 2^{40},x\bmod 3^{24},x\bmod 5^{16})$ est une bijection $S\leftrightarrow S_2\times S_3\times S_5$.

**2) Cardinaux.** Comptage local
$$N(p,a,n)=1+\!\!\sum_{1\le b<a,\,2b\ge n}\!\!\varphi(p^{n-b})+\!\!\sum_{a<b\le n,\,b+a\ge n}\!\!\varphi(p^{n-b})+\big[a\le n\big]\big(n\le2a\,?\,\varphi(p^{n-a}):p^a\big):$$
$$N(2,8,40)=513,\quad N(3,6,24)=1459,\quad N(5,4,16)=1251.$$
$$|S|=513\cdot1459\cdot1251=\boxed{936\,332\,217}.$$
Éléments premiers avec $N$ : seul le représentant $X\equiv0\pmod{p^{n_p}}$ n'est pas une unité locale, donc $512\cdot1458\cdot1250=\boxed{933\,120\,000}$.

Le degré $3$ ne borne pas le nombre de racines car $\Z/N\Z$ n'est pas intègre : le produit peut être $\equiv0$ sans qu'aucun facteur ne le soit (racines « mixtes » où $v_p(X-1)+v_p(X-1-D)\ge n_p$).

**3) Somme.** $\sum_{x\in S}x\bmod N=\boxed{20\,425\,381\,512\,310\,255\,170\,453\,869\,286\,720\,000}$ (sommes locales $29\,859\,840\,512$, $85\,030\,561\,458$, $72\,900\,001\,250$ recombinées par TCR).

**4) Couples.** Localement, $x+y\equiv1\pmod{p^{n_p}}$ n'admet que $(0,1)$ et $(1,0)$ (si $x,y\equiv1\pmod p$ alors $x+y\equiv2\not\equiv1$). Donc $\boxed{8}$ couples, obtenus en choisissant indépendamment $(0,1)$ ou $(1,0)$ pour chaque premier. Ceux sans coordonnée $\in\{0,1\}$ : $\boxed{6}$ (les deux couples extrêmes $(0,1),(1,0)$ sont exclus).

**5) Période.** $T$ est une période ssi $S+T=S$. Localement $T_p\equiv0\pmod p$ (car $S_p$ contient des éléments $\equiv1\pmod p$) et $T_p\in S_p$, or $S_p\cap\{0\bmod p\}=\{0\}$, donc $T_p=0$. La période minimale est $\boxed{N}$.

**6) Classification locale générale.** Voir formule ci-dessus ; le régime change à $n=2a$ : pour $n\le2a$ le terme $b=a$ vaut $\varphi(p^{n-a})$, pour $n>2a$ il vaut $p^a$. Le cas $p=2$ est inclus sans traitement spécial (la formule est uniforme ; seule la valeur $\varphi(2)=1$ et $\sum$ des unités mod $2$ diffèrent).

**7) Vérificateur.** Voir ci-dessous.

## Preuves et certificats

**Classification locale (certificat exhaustif).** Testée par force brute sur $p^n$ pour **34 triplets** $(p,a,n)$ couvrant $p\in\{2,3,5\}$, $a\in\{1,\dots,6\}$, $n\le a$, $n=2a$, $n>2a$ : **tous concordent**. Exemples de changement de régime : $p=3,a=2$ donne $2,4,4,10,19,19,19,19$ pour $n=1..8$ (saut à $n=2a=4$) ; $p=2,a=3$ donne $2,3,3,5,5,9,17,17,17$.

**Cardinaux.** $513\cdot1459\cdot1251=936332217$ et $512\cdot1458\cdot1250=933120000$ (calcul déterministe). Contrôle indépendant : sur l'analogue réduit $N'=2^6 3^4 5^4$, $D'=2^2 3^2 5^2$ (mêmes rapports $n/a$), la force brute sur $N'=3\,240\,000$ donne $|S|=2340$, premiers avec $N'$ : $1800$, couples : $8$ (dont $6$ sans $0/1$) — identiques aux formules.

**Somme.** Formule locale (somme des unités $=\tfrac12 p^k\varphi(p^k)$, cas $b=a$ : $w=d+p^{n-2a}t$) vérifiée par force brute sur **20 cas** ; recombinaison TCR exacte.

**TCR.** Les modules $2^{40},3^{24},5^{16}$ sont deux à deux premiers entre eux ; la bijection $S\leftrightarrow\prod S_p$ est le TCR.

## Pièges traités

- **« Produit nul ⇒ facteur nul » interdit** : traité par valuation $p$-adique $v_p(X)+v_p(X-1)+v_p(X-1-D)\ge n_p$ sur chaque puissance première, puis TCR. C'est la source des racines mixtes.
- **Multiplicités au seuil $n=2a$** : le terme $b=a$ bascule de $\varphi(p^{n-a})$ ($n\le2a$) à $p^a$ ($n>2a$) ; les seuils $2b\ge n$ et $b+a\ge n$ sont inclusifs (racines comptées avec multiplicité aux bornes).
- **Hensel** : non invoqué comme lemme de relèvement de racine simple ; la classification est obtenue par valuation directe, valable même quand les racines ne sont pas simples (cas $b=a$, $p\mid D$).
- **Entiers exacts** : tous les résultats sont des entiers exacts, jamais d'approximation ; cardinaux recoupés par une seconde méthode (force brute sur module réduit).

## Limites / impossibilités

- La force brute directe sur $N\approx4{,}7\cdot10^{34}$ est impossible ; la validité repose sur la **structure locale + TCR**, dont la formule locale est prouvée par énumération exhaustive sur petits modules (34 cas) mais **extrapolée** aux grands exposants par l'argument de valuation (démonstration, non énumération).
- La formule locale est **indépendante de $d=D/p^a$** pour $n\le2a$, mais **dépend de $d\bmod p^{n-2a}$** pour $n>2a$ (cas $b=a$) ; ici $n_p>2a_p$ pour les trois premiers, donc la somme locale utilise bien $d\bmod p^{n_p-2a_p}$.
- Le vérificateur proposé (question 7) distingue : **vérification expérimentale** (force brute sur petits $p^n$, comparaison à la formule) et **démonstration exhaustive** (l'argument de valuation couvre tous les $b$, donc est une preuve, pas un échantillon). Aucune garantie ne peut être donnée par simple échantillonnage sur les grands modules ; seule la preuve locale + TCR certifie les valeurs finales.
