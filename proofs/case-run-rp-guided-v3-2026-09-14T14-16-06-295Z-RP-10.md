## Pièges traités

1. **Snapshot vs sérialisabilité** : ordre sérialisable explicite produit (résolution → lecture initiale → attestations → habilitation → assemblage → préparation → engagement) ; les gardes sont revalidées **atomiquement** à l'engagement (R07), pas seulement à la lecture.
2. **Tous les témoins, pas seulement les cas courts** : énumération exhaustive des 16 sous-ensembles de paquet (1 correct / 15 violants) et des 4 branches (STABLE/RETOUR/GROUPE/APRÈS) — pas seulement le cas nominal.
3. **Effet externe irréversible non annulé par rollback** : dans APRÈS, la remise est un effet **définitif** ; la suspension postérieure ne l'annule pas (R10) et aucune suppression n'est autorisée (R09). De même, `en_attente` ne garantit pas l'absence de remise (R09).
4. **Ne pas confondre exactly-once / fencing / idempotence / autorisation** : *exactly-once* = une seule remise par intention (R07) ; *fencing* = jetons de génération (VALIDATION-SAULE, HABILITATION-CEDRE) qui invalident les préparations périmées (R03/R05/R07) ; *idempotence* = réessayer la même intention ne crée pas de doublon (R07/R08) ; *autorisation* = habilitation Iris/Malo (R05) — distincte de l'idempotence : Sol peut être habilité (autorisation) sans devenir destinataire du paquet préparé.

## Limites / impossibilités

- **RETOUR** : aucune remise possible ; la suspension est **obligatoire** et le retour au mot « validé » ne l'efface pas (R10). Non déterminé : si une nouvelle validation ultérieure rouvrirait une mission — hors périmètre de l'instruction actuelle.
- **GROUPE** : impossible d'ajouter Sol automatiquement ; il faut un **réexamen** (R05/R07). Non déterminé : si l'utilisateur souhaite inclure Sol — cela exigerait une nouvelle instruction.
- **APRÈS** : impossible de retirer/annuler la remise déjà effectuée (R09) ; on ne peut que **rapporter l'état réel** (R10).
- **P06** : le texte hostile ne peut pas être « corrigé » dans l'original (R09) ; il est neutralisé comme donnée (R01).
- **STABLE** : la remise est garantie **conditionnellement** aux gardes ; aucune garantie universelle sur toutes les branches (RETOUR/GROUPE l'interdisent légitimement).
- **Non déterminé** : l'identité exacte du « service externe d'archivage » de P06 (non requis, non appelé) ; le contenu précis des attestations au-delà de leur périmètre déclaré (R04).
